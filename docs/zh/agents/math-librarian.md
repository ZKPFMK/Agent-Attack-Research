# 数学馆员角色已退休

本仓库现在面向 LLM agent 与多智能体系统攻击研究，默认工作流不再包含密码学数学馆员角色。该路径仅作为旧中文链接的兼容说明，不应在新的 project 中派工。

- 攻击面、访问点、victim 和 success criterion：使用 [`threat-modeler`](../../../agents/threat-modeler.md)。
- 用户知识库中的论文定位和最近邻：使用 [`kb-curator`](../../../agents/kb-curator.md)。
- 公开文献检索、阅读笔记和引用核验：使用 [`lit-scout`](../../../agents/lit-scout.md)。
- 可运行的实验和 rate/CI：使用 [`experimenter`](../../../agents/experimenter.md)。

旧项目中的 `MATH-REFS.md`、Sage、Lean 和密码学教材索引不属于新的 Agent Attack workflow；历史资料可以保留在上游目录，但不得作为新项目的默认依赖。
