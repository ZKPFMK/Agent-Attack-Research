# Agent-attack research map

```text
P0 scope + ethics + KB path
        |
P1 public literature + KB positioning + defenses/benchmarks
        |
P2 idea mining: access point -> mechanism -> naive control -> kill switch
        |
P3 threat model + reachability + judge validation
        |
P4 pinned attacks/defenses/benchmarks
        |
P5 interleaved trials: ASR/utility/false-trigger/stealth/cost
        |
P6 falsification: judge, base model, statistics, adaptive defense, novelty
        |
P7 paper + figures + evidence links
        |
P8 review + disclosure + redacted artifact + human approval
```

The three primary surfaces are 01 external interaction, 02 internal cognition and 03 multi-agent collaboration.
Folders 04–09 provide defense, framework, benchmark and misinformation context. Backward edges are expected:
P6 can return to P2/P3/P5 and P8 can return to P5/P7.
