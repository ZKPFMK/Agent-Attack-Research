# Reading lists for agent-attack research

The user's local KB and paper folders are the primary seed. This directory keeps method-level pointers,
not copyrighted PDFs or private research material. Public entries are verified by `skills/bib-verify` before
appearing in a project's refs.bib.

The older crypto lists remain as historical files from the upstream toolkit; new projects should use
`agent-attacks.md` and `skills/paper-search`.
