# cra-core

Typed state layer for the agent-attack research blackboard: lossless Markdown tables, claim/evidence invariants,
P0–P8 gates, event log, file lock and `cra` CLI. A claim enters paper/ only after falsification; every printed
number needs EVIDENCE.md; threat-model and ethics files are part of the P3/P8 workflow.

```bash
pip install -e lib/core
cra init /path/to/project
cra status -p /path/to/project
```
